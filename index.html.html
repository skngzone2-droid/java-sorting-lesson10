PART 1

Review: Arrays

Explanation: An array stores multiple values of the same data type under one variable name. Each value is an element. An index tells the position of an element, and Java array indexes begin at 0. numbers.length gives the number of elements.

int[] numbers = {40, 10, 30, 20, 50}; for (int i = 0; i < numbers.length; i++) { System.out.println(numbers[i]); }

Code explanation: The array has five values. The loop starts at index 0 and continues while i < numbers.length. Each pass prints one element.

Sa madaling Tagalog: Ang array ay lalagyan ng maraming value sa iisang variable. Ang index ay bilang ng posisyon na nagsisimula sa 0. Ginagamit ang for loop para maipakita ang bawat element.

What Is Sorting?

Explanation: Sorting means arranging data in a chosen order.

Ascending: smallest → largest

1020304050

Descending: largest → smallest

5040302010

Original array: {40, 10, 30, 20, 50}

Ascending: {10, 20, 30, 40, 50}. Descending: {50, 40, 30, 20, 10}.

Sa madaling Tagalog: Ang sorting ay pag-aayos ng values. Sa ascending, mula pinakamababa hanggang pinakamataas. Sa descending, mula pinakamataas hanggang pinakamababa.

PART 3

Introduction to Bubble Sort

Explanation: Bubble Sort compares neighboring (next-to-each-other) elements. For ascending order, if the left value is larger than the right value, the program swaps them. Repeated passes move larger values toward the right side.

Sa madaling Tagalog: Paghahambingin ang magkatabing numbers. Kung mas malaki ang nasa kaliwa kaysa sa nasa kanan, pagpapalitin sila. Uulitin ang paghahambing hanggang maayos ang pagkakasunod-sunod.

Passes for {5, 2, 4, 1}

  1. Pass 1: {2, 4, 1, 5}
  2. Pass 2: {2, 1, 4, 5}
  3. Pass 3: {1, 2, 4, 5}

Why? Pass 1 compares 5 and 2 (swap), 5 and 4 (swap), then 5 and 1 (swap). Pass 2 compares 2 and 4 (no swap), then 4 and 1 (swap). Pass 3 compares 2 and 1 (swap).

PART 4

Java Code for Bubble Sort

public class BubbleSortExample { public static void main(String[] args) { int[] numbers = {5, 2, 4, 1}; for (int i = 0; i < numbers.length - 1; i++) { for (int j = 0; j < numbers.length - 1 - i; j++) { if (numbers[j] > numbers[j + 1]) { int temp = numbers[j]; numbers[j] = numbers[j + 1]; numbers[j + 1] = temp; } } } for (int i = 0; i < numbers.length; i++) { System.out.println(numbers[i]); } } }

Expected output

1 2 4 5
  • int[] numbers declares an integer array.
  • The outer loop repeats passes through the array.
  • The inner loop compares neighboring elements during a pass.
  • if (numbers[j] > numbers[j + 1]) checks whether the pair is in the wrong order for ascending sorting.
  • temp temporarily holds one value so it is not lost during the swap.
  • The final loop prints the sorted values.
Why is temp needed? If you overwrite numbers[j] before saving its original value, that value is lost. temp safely holds it while the two values exchange places.
Sa madaling Tagalog: Ang outer loop ay para sa paulit-ulit na passes; ang inner loop ay para sa paghahambing ng magkatabing values. Ang temp ay pansamantalang taguan ng value habang nagpapalitan ang dalawang number.

PART 5

Sorting in Descending Order

To sort from largest to smallest, change the comparison operator from > to <.

if (numbers[j] < numbers[j + 1]) { int temp = numbers[j]; numbers[j] = numbers[j + 1]; numbers[j + 1] = temp; }

For {5, 2, 4, 1}, the expected descending output is:

5 4 2 1
Sa madaling Tagalog: Para descending, kapag mas maliit ang nasa kaliwa kaysa sa nasa kanan, pagpapalitin sila para mapunta sa unahan ang mas malaking number.

Key terms

  • Array: a collection of values stored under one variable name.
  • Element: one value inside an array.
  • Index: a position number, beginning at 0 in Java.
  • Sorting: arranging values in a chosen order.
  • Ascending: smallest to largest.
  • Descending: largest to smallest.
  • Algorithm: a step-by-step method for solving a problem.
  • Swap: exchange the positions/values of two elements.
  • Bubble Sort: a sorting algorithm that compares neighboring elements and swaps out-of-order pairs.
